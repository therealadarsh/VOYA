Draft. This page is not a privacy policy. Legal wording has not been supplied.

What the software stores today

  • A hash of the account email and a hash of the session token
  • Trip requests: destination, dates, budget, party size, interests
  • Spend amounts, category, day, and a short note
  • Opt-in memory keys: interests, pace, tip percent, firmness, adults
  • Feedback messages you submit. A message may include an optional contact address.
  • Magic-link tokens until they are used or they expire

The software does not ask for income. Stored coordinates use at most 3 decimal places.

To ask for a feedback message and its contact address to be deleted, send another feedback note that names the message to remove. The operator deletes that stored row. No public deletion address is listed here, because the owner has not supplied one.
